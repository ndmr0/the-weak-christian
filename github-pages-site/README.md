# The Weak Christian Public Pages

This folder contains the public pages needed for App Store submission.

Upload these files to a public GitHub repository and enable GitHub Pages from the `main` branch.

After GitHub Pages is enabled, the App Store URLs will look like:

- `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/privacy-policy.html`
- `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/support.html`
